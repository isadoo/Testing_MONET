# Ramirez-Valiente case study

- They analyzed two species, *Quercus faginea* and *Quercus lusitana*. 
- individuals of *Q.faginea* were analyzed in two separate common gardens: outdoor common garden (OC), and greenhouse common garden (GH)
- However, since they come from the a similar set of wild populations, the genetic data comes from adult trees in wild populations, we can use the same $\Theta_P$ for both *Q.faginea* experiments.
