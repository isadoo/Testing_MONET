Phenotypic data for Geranium carolinianum measured in a common garden. Stable isotope data are in a separate file ("Gercar qst SI data.txt"). 
pop = source population
reg = source region (US = United States; CN = China)
fam = maternal family identifier
blk = block
germinated = date scarified for planting
planted = date germinating seeds planted in flats (2 days after germinated)
juvlf_date = date of full expansion of the 3rd leaf (juvenile establishment time)
juvlf_length = length of 3rd leaf on juvlf_date (cm; proxy for juv. rosette size)
lfmass = leaf mass (g)
lfarea = leaf area (cm2)
SLA = specific leaf area (mm2/mg)
dff = days to first flower
rose_dia = adult rosette diameter (cm)
harvest_ht = height at harvest (cm)
boltA = number of undamaged bolting stems
boltB = number of partially damaged bolting stems (some flowers intact)
boltC = number of completely damaged bolting stems (all flowers destroyed)
seedwt = mass of ten seeds (g)
repwt = reproductive biomass (g)
vegwt = aboveground vegetative biomass (g)
rootwt = root biomass (g)
totalAG = total aboveground biomass (g)
