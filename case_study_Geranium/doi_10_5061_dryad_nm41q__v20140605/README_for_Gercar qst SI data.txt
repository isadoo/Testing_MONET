Stable isotope data for common-garden Geranium carolinianum.
reg = source region (US = United States; CN = China)
pop = source population
fam = maternal family
blk = block used in analysis
oldblk = block in common garden (when mortality resulted in insufficient family replicates within a block, plants from adjacent blocks were used)
loc = randomized plant location within block (not used in analysis)
ACL = sample number used for processing at the Analytical Chemistry Lab at the University of Georgia (not used in analysis)
weight = sample mass (g)
totN = percent total N
delN15 = delta 15N (not used in analysis)
totC = percent total C (not used in analysis)
delC13 = delta 13C
